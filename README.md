# Paper Note

在浏览器里读论文、记笔记：左边是 PDF，右边是笔记。

在线使用：<https://sikong206573.github.io/Paper_Note/>

## 怎么用

打开 PDF（点「打开 PDF」或直接把文件拖进左侧），然后用三种方式记笔记：

- **引用原文**：在 PDF 上选中文字，点弹出的「引用到笔记」，或者把选中的文字直接拖到右侧想放的位置。被引用的段落会在 PDF 上留下黄色高亮。点笔记里的「第 N 页」会跳回原文并闪烁提示；点 PDF 上的高亮会跳到对应的笔记。每条引用下面可以写批注。
- **截图**：点「框选截图」，在论文上拖出一个框，就会以高清重新渲染这块区域并存为图片笔记（适合截图表和公式）。也可以用 `Ctrl+V`（Mac 上 `⌘+V`）粘贴任意截图，或者把图片文件拖进笔记区。
- **手写**：点「文字」或在笔记末尾点一下，直接写。
- **翻译**：选中英文后点「翻译」，选区下方会弹出中文译文，可以复制，或者连同译文一起引用到笔记。笔记里已有的引用也能点「翻译」补上译文；勾选「引用时自动附上译文」后，每次引用都会自动翻译。译文可以手动修改，清空后可以重新翻译。

新的笔记会插在当前选中的那条后面。

| 操作 | 方法 |
| --- | --- |
| 新建一段文字 | 在任意笔记里按 `Ctrl/⌘ + Enter` |
| 调整顺序 | 拖动笔记左侧的把手，或按 `Alt + ↑/↓` |
| 删除 | 笔记右侧的垃圾桶（可以撤销）；空的文字段按退格键 |
| 缩放 PDF | `−` / `+`、「适合宽度」，或按住 `Ctrl/⌘` 滚动滚轮 |
| 调整左右宽度 | 拖动中间的分隔条 |
| 退出截图 | `Esc` |

## 保存与导出

笔记和 PDF 自动保存在当前浏览器里（IndexedDB）。以后再打开同一个 PDF，笔记会自动恢复；读过的论文都在「论文库」里。

数据只存在这台电脑的这个浏览器里，清除浏览器数据会一起删除，所以建议定期导出：

- **Markdown 文件**：单个 `.md`，图片直接嵌在文件里
- **Markdown + 图片文件夹**：`.zip`，适合放进 Obsidian、Typora
- **网页文件**：`.html`，用浏览器打开后可以打印成 PDF
- **备份笔记**：`.json`，在另一台电脑上打开同一个 PDF 后用「从备份导入」恢复

## 隐私

PDF 只在你的浏览器里读取和渲染，不会上传到任何服务器。页面只会从 CDN 下载 PDF 阅读组件（pdf.js）。

## 关于翻译

翻译使用浏览器内置的 Translator API，在你的电脑上本地运行：免费，不需要 API key，文字不会发到任何服务器。

- 需要桌面版 Chrome 138 或更新版本，或 Edge 148 或更新版本。手机浏览器、Firefox 和 Safari 暂不支持，这些浏览器里「翻译」按钮会显示为灰色。
- 第一次翻译时浏览器会下载翻译模型，界面上会显示下载进度，之后都可以离线翻译。
- 译文质量是通用机器翻译水平，专业术语可能需要手动修改。

## 已知限制

- 扫描版 PDF 没有文字层，不能选中文字引用，可以用「框选截图」代替。
- 同一篇论文以文件指纹识别；如果 PDF 文件本身被修改过，会被当成一篇新论文。

## 部署到 GitHub Pages

整个工具就是一个 `index.html`，不需要构建。

1. 把 `index.html` 和 `README.md` 放到仓库根目录并提交到 `main` 分支。
2. 打开仓库的 **Settings → Pages**，在 **Build and deployment** 下把 **Source** 设为 **Deploy from a branch**，分支选 `main`，目录选 `/ (root)`，保存。
3. 等一两分钟，访问 `https://sikong206573.github.io/Paper_Note/`。

本地试用：在这个目录运行 `python3 -m http.server`，然后打开 <http://localhost:8000>。

## 技术说明

- 单文件，原生 JavaScript，无框架
- [pdf.js](https://mozilla.github.io/pdf.js/) 3.11.174：渲染 PDF 和文字层；优先从 cdnjs 加载，失败时自动换 jsDelivr
- [JSZip](https://stuk.github.io/jszip/) 3.10.1：只在导出 zip 时加载
